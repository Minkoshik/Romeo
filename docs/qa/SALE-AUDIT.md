# Проверка перед передачей исходников — 12 октября 2026

Модель продажи: только код, установку организует покупатель. Сайт не опубликован; настоящих списаний не было. Проверка включала код/структуру, автоматические тесты, PostgreSQL, HTTP и ручные сценарии в Chromium. Она не доказывает отсутствие всех возможных ошибок.

## Найденные и исправленные ошибки

1. Повторное нажатие активного раздела админки очищало данные, но не инициировало загрузку; панель оставалась пустой. Активный раздел теперь сохраняет данные. Ручной повтор проверен во всех девяти разделах.
2. Поля индивидуальных назначений мастера принимали текст `abc`: `NaN` превращался в `null` в JSON и сохранялось базовое значение без сообщения. Добавлены числовые поля, проверка конечности/безопасного целого/точности и обработка ошибки формы. Пустое необязательное значение отличается от нуля. Цена вводится в RUB с точностью до копейки; длительность/буфер — целые минуты. Проверены отклонение 1.999 RUB и сохранение 1250.50 RUB.
3. Линтер захватывал временные локальные QA-скрипты. В `eslint.config.mjs` добавлены исключения `.local/**` и `artifacts/**`; эти каталоги исключены также из TypeScript, чтобы копии исходников при упаковке не участвовали в проверке проекта. Исходный код продолжает проверяться.

## Границы проверки и передачи

Автотесты покрывают гонки/пересечения, идемпотентность, истечение без браузера, повторные/поздние события, чужой доступ и серверную проверку цены. Ручная проверка охватывает перечисленные пользовательские сценарии; не каждый набор всех возможных значений/кнопок во всех браузерах.

Firefox/WebKit, нагрузка, реальный банковский провайдер, доставка уведомлений, импорт ICS внешним календарём, удалённые nginx/systemd/TLS и восстановление серверного backup не проверялись. Нет универсального bootstrap настоящей пустой базы и самостоятельного восстановления пароля. Демонстрационные подписи/metadata/noindex требуют подготовки под рабочий салон. План передачи и разделение обязанностей — в [HANDOVER.md](../HANDOVER.md).
